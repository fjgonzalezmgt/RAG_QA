# Quality Knowledge Base

Place SOPs, procedures, CAPA reports, audits, complaints, specifications,
quality reports, lessons learned, DMAIC projects, KPI reports, and QMS
documents in this folder for ingestion.

Recommended file naming pattern:

```text
<document_type>__<plant>__<process>__<product-or-customer>__<code>__rev-<revision>.pdf
```

Example:

```text
SOP__PlantaNorte__Empaque__SKU-100__SOP-QA-014__rev-03.pdf
```
